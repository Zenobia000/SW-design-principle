# 實戰 Notebooks

> 互動式程式碼範例 - 邊學邊做

## 📚 內容說明

本目錄包含 5 個 Jupyter Notebook,每個對應一個 SOLID 原則,提供可執行的程式碼範例。

## 📖 Notebooks 列表

### [01-單一職責原則_SRP.ipynb](./01-單一職責原則_SRP.ipynb)
**訂單處理系統案例**

- 問題:訂單類別負責驗證、計算、保存、通知
- 重構:分離為 `OrderValidator`、`PriceCalculator`、`OrderRepository`、`NotificationService`
- 學習重點:職責分離、內聚性

---

### [02-開放封閉原則_OCP.ipynb](./02-開放封閉原則_OCP.ipynb)
**折扣策略系統**

- 問題:每次新增折扣類型都要修改代碼
- 重構:使用策略模式,創建 `DiscountStrategy` 抽象
- 學習重點:策略模式、擴展而非修改

---

### [03-里氏替換原則_LSP.ipynb](./03-里氏替換原則_LSP.ipynb)
**鳥類移動系統**

- 問題:鴕鳥繼承了鳥類的 `fly()` 方法但不能飛
- 重構:分離為 `FlyingBird` 和 `NonFlyingBird`
- 學習重點:行為一致性、正確的繼承設計

---

### [04-依賴倒置原則_DIP.ipynb](./04-依賴倒置原則_DIP.ipynb)
**資料庫抽象層**

- 問題:應用直接依賴 MySQL 實現
- 重構:引入 `Database` 抽象,依賴注入
- 學習重點:依賴抽象、依賴注入

---

### [05-介面隔離原則_ISP.ipynb](./05-介面隔離原則_ISP.ipynb)
**員工管理系統**

- 問題:機器人被迫實現 `eat()` 和 `sleep()` 方法
- 重構:分離為 `Workable`、`Eatable`、`Sleepable` 接口
- 學習重點:接口分離、角色設計

---

## 🚀 如何使用

### 1. 啟動 Jupyter Notebook

```bash
cd "D:\python_workspace\Sunny_DA_Learning\SW-Design-principle\System-design\SOLID\02-實戰Notebooks"
jupyter notebook
```

### 2. 按順序學習

建議按照 01 → 02 → 03 → 04 → 05 的順序學習。

### 3. 實踐練習

每個 Notebook 包含:
- ❌ 違反原則的初始代碼
- ✅ 重構後的代碼
- 💡 設計說明
- 🎯 練習題(可選)

### 4. 動手修改

- 嘗試修改代碼,觀察效果
- 添加新功能,驗證設計的可擴展性
- 思考其他重構方案
